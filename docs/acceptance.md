# V1 交互验收标准

状态：**待实现**。每条为可验证的 Done 条件，不代表当前已通过。每个用户可见交互不应成为死按钮。

## A. 迁移基础

- [ ] `pnpm install --frozen-lockfile` 安装成功，lockfile 与 package 元信息匹配。
- [ ] `pnpm lint`、`pnpm typecheck`、`pnpm test`、`pnpm build` 全部通过，CI 状态可追溯。
- [ ] React/Ant Design/路由/主题/命令搜索/移动 Drawer 可用，深链接刷新正常。
- [ ] 旧 `/customers`、`/projects`、`/orders`、`/users` 路由不存在；旧客户、订单等业务模块和样例数据已移除。
- [ ] 新仓库无需依赖模板仓库的 runtime、submodule 或 workspace。

## B. 采集与评论

- [ ] 可用三种入口创建任务（文件、URL、关键词），任务出现在列表且状态/进度可查。
- [ ] 模拟进度不产生外部请求；任务完成后真实增加所关联的帖子/评论记录。
- [ ] 300 帖、约 10k 评论与 4 专题数据确定性可重置，外键无断链。
- [ ] 列表关键词、日期、状态筛选与排序生效且同步 URL，刷新和前进/后退可恢复。
- [ ] 出现空数据/失败/非法输入时页面明确告知并提供合理恢复操作。

## C. AI 研判与复核

- [ ] 选择规则版本和评论集创建分析任务，可见进度与执行结果。
- [ ] 每项结果包含多维评分、情绪类别、标签、证据、规则版本、置信度。
- [ ] 工作台能按评分区间/标签/复核状态筛选，点击行可查原帖上下文。
- [ ] 复核“确认/存疑/驳回”操作保存记录，刷新列表后状态正确。
- [ ] 改变复核结论后 Dashboard 待办数和复核队列同步，历史复核不可丢失。
- [ ] AI 结果明确为模拟输出，不推断私人政治立场或个人风险。

## D. 专题与报告

- [ ] 可创建专题并关联评论，专题汇总与趋势来源于同一数据集。
- [ ] 报告生成保存专题与数据快照，正文可以编辑、预览。
- [ ] 导出文件实际存在且与已保存正文一致；分析数据导出覆盖当前条件下全部记录。
- [ ] 无论报告是否已有缓存，统计数据来源、时间范围、规则版本清楚可追溯。

## E. 非功能与无障碍

- [ ] 桌面、移动导航可操作，键盘可打开 Ctrl/⌘K 搜索，焦点可见。
- [ ] 10k 评论时表格分页交互正常，不一次性渲染全部 DOM。
- [ ] 加载、空、失败、重试状态清楚；危险动作二次确认。
- [ ] 模拟数据会话内保持一致，刷新重置且不会声称真正持久化。
- [ ] 无真实数据采集 / 登录 / 后台 / 模型调用；所有外部依赖遵守当前范围。
