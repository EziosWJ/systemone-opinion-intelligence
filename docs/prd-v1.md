# PRD — SystemOne 舆情智能研判平台 V1

- 版本：1.0.0（产品需求基线）
- 日期：2026-10-26
- 交付目标：客户可操作的完整交互式 Demo（后续开发目标）
- 产品定位：针对公开社交媒体评论的 AI 辅助舆情分析平台，**微博评论优先**；微博正文用于上下文，支持专题、报告与人工复核。
- 核心用户：单用户分析员；无账号、角色、鉴权。
- 视觉：专业数据分析平台，蓝色中性色，顶部业务分组导航、浅/深主题。
- 演示规模：4 个虚构社会热点事件专题、300 条模拟微博正文、约 10,000 条模拟评论。统计须来自同一套数据源而非静态硬编码。

## 1. 成功定义

用户应能够在 Demo 内完成：**新建采集任务 → 取得关联微博/评论 → 创建 AI 分析任务 → 根据多维评分筛选 → 查看原微博上下文与依据 → 人工复核 → 归入专题 → 生成并编辑专题简报 → 导出文件**。

模型推断须被呈现为辅助性、可撤销的判断。分数不用于推断发言者的私人政治立场、可信度或真实主观意图。对反讽/隐喻等语义只能输出有依据的可能性、置信度及上下文限制，供人工核实。

## 4. 功能性需求

### FR-01 数据采集与数据源

- 创建任务支持 `url`（指定微博链接）、`keyword`（关键词/话题）、`import`（文件上传）。文件格式 CSV/XLSX/JSON 的解析与结构校验由业务实现，通用 MockUpload 仅模拟选择/进度，不等同真实导入。
- 任务列表展示类型、条件、状态、已处理数、总数、创建时间、最后更新时间和错误原因。演示任务可模拟逐步推进，无真实外部请求。
- 帖子与评论存在完整外键关联；评论详情必须可查看对应原微博与发布时间；缺失/删除上游关联应显示明确错误或降级视图。
- 查询支持关键词、时间段、来源、状态、排序与分页；查询条件写入 URL，可分享和恢复。

### FR-02 AI 多维评分

- 支持创建分析任务，选择数据范围、规则模板、规则版本、是否对新采集评论自动研判。
- 演示运行应有执行进度、成功/失败状态和结果批次；不存在真实模型推理时统一标注“模拟评分”。
- 每条结果至少输出：评论 ID、规则 ID/版本、任务 ID、话题相关性（0–100）、反讽表达可能性（0–100）、情绪类别、复核优先级（0–100）、标签、文本依据、解释、置信度（0–1）。
- 必须区分**话题相关性、反讽可能性、优先级与置信度**；不能合并为含义不明的统一“风险分”。
- 对文本含混或缺乏上下文的情况允许 `unclear`/待复核，不能强制猜测表达意图。

### FR-03 综合研判与人工复核

- 工作台使用高密度表格，支持评分区间、规则、标签、状态、所属专题、时间、关键词筛选及批量选择。
- 行详情抽屉展示评论原文、原微博、分析依据、各维度数值、规则版本及历史复核。
- 人工复核可“确认 / 存疑 / 驳回”，并保存操作时间与备注；允许重新复核，以最新决策为当前态，保留历史记录。
- 复核状态更新应使任务、工作台与驾驶舱的同源指标正确变化；重试或网络错误不产生重复决策。

### FR-04 综合态势首页

- KPI：采集评论量、已研判量、待复核量、采集任务状态；分布：热点专题、话题、情绪、评分区间；趋势：采集与分析量的每日变化。
- 所有 KPI 和图表来自 mock 聚合接口，同一筛选周期与同一快照；点击指标可进入带 URL 查询条件的对应列表。
- 统计需定义口径和时间范围，不使用随机前端常量制造不一致展示。

### FR-05 专题与报告

- 创建专题，设置名称、摘要、关键词，将微博/评论关联到专题；可查看专题评论趋势、表达分布和代表性来源。
- 生成报告时绑定当前专题、统计区间与规则版本快照，包含：数据说明、趋势、观点、典型评论及来源、模型推断与人工复核结论、不确定性与待核查事项。
- 报告支持编辑 Markdown / 结构化正文，预览、导出（至少 DOCX 或 PDF/HTML 中一种，另支持 CSV/XLSX 研判数据）；导出必须从当前编辑内容生成真实文件，不是死按钮。
- 引用评论要保留对应 ID、帖文来源与时间；不应把 AI 解释描述成已证实的舆论事实。

## 5. 通用交互 / 质量

- 路由：React Router Data Router，页面懒加载；页面菜单/面包屑/全局命令搜索共享配置。
- 交互：查询/重置/分页/排序/列显隐/跨页选择/导出；Loading、Empty、Error、Retry；危险操作二次确认；按钮无空操作。
- 响应式：桌面顶部单行导航、窄屏 Drawer，Ctrl/⌘+K 搜索，键盘焦点可见。
- 状态：React Query 负责 API 缓存，URL 负责筛选/分页，Zustand 只用于确有必要的局部跨组件状态。
- 演示：MSW 内存种子数据可复现、会话内联动，刷新后重置。演示性质在 UI 与 README 显著标明。

## 6. 明确不包含

真实微博爬虫或未授权 API 访问、真实大模型/JEV 推理、实时预警服务、数据库、账号体系、权限控制、多人协作、消息推送、生产部署、移动端原生 App、规模化分布式处理与真实个人政治画像。

## 7. 依赖与开放问题

- 确定 Demo 报告的首选导出格式（开发默认 HTML + XLSX；新增 DOCX/PDF 前需决定渲染规范）。
- JEV 适配仅定义接口缝，真实接入作为后续独立里程碑。
- 演示内容全部应为明确标识的虚构或已授权脱敏数据；不使用真实用户账号作为模拟身份。
